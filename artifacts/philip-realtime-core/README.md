# Philip Realtime Core (Phase 1)

Unpaid local/mock harness for a clean-slate native realtime speech-to-speech Philip prototype.

## Constraints

- No paid provider calls
- No deploy / push / production changes
- No import of legacy Voice Lab ordinary-path machinery

## Quick start

```bash
cd artifacts/philip-realtime-core
npm test
npm run cost-model
```
